# תחזוקה ובדיקות

## לפני כל מסירה

```bash
npm run build
git diff --check
git status --short
```

לאחר מכן יש לבדוק ידנית:

- הפתיח מסתיים והגלילה משתחררת.
- כפתור הדילוג עובד.
- הטבעת אינה נחתכת בדסקטופ ובמובייל.
- גרירה אופקית אינה חוסמת גלילה אנכית בטאץ'.
- כפתור 360 מעלות עובד במקלדת.
- שלוש המתכות משנות את החומר ואת תווית הבחירה.
- המעבר למקטע האנטומיה חלק בשני הכיוונים.
- תוויות האנטומיה אינן חופפות בדסקטופ.
- רשימת האנטומיה מוצגת במובייל.
- Reduced Motion מציג מצב יציב ללא נעילה.
- WebGL failure משאיר אתר שמיש.

## קבצים שנוצרים אוטומטית

ה־Build מעדכן את `models/ring.glb`, ‏`src/ringMeta.json` ו־`src/three/ringModel.js`. המודל נטען באתר מה־GLB; קובץ ה־Base64 נשמר כרגע כתוצר תאימות של מחולל המודל ואינו נכנס ל־bundle.

## שדרוג תלויות

יש לשדרג יחד ולבדוק תאימות בין `three`, ‏`@react-three/fiber`, ‏`@react-three/drei`, ‏`react` ו־`react-dom`.

לאחר שדרוג יש לבצע QA חזותי ליהלום, משום ש־`MeshRefractionMaterial` ו־shader chunks רגישים לשינויי גרסה.

## כללי קוד

- יש למחזר Vector3, Euler ואובייקטים זמניים בתוך hot paths.
- אין להקצות textures או materials בכל פריים.
- שינוי ערך material קיים עדיף על החלפת material.
- יש להוסיף cleanup לכל listener ולכל משאב GPU בבעלות הקומפוננטה.
- אין להפעיל render loop נוסף לצד R3F.
- יש לשמור על HTML חלופי לכל פעולה עסקית חשובה.

## עדכון התיעוד

כאשר מוסיפים מקטע, חומר, Quality Tier או state חדש, יש לעדכן את מסמך הארכיטקטורה ואת המסמך המקצועי הרלוונטי. כאשר משתנה תהליך Build או פריסה, יש לעדכן גם את `README.md` ואת `DEPLOYMENT.md`.
