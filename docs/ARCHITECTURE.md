# ארכיטקטורה

## תמונת מצב

הפרויקט בנוי כשתי שכבות שעובדות יחד:

1. שכבת DOM רגילה עבור תוכן, ניווט, כפתורים, SEO ונגישות. הרצף החזותי: Hero בהיר (סטודיו באור יום) → אנטומיה וצורות כהים (חדר תצוגה) → סיום בהיר כגיליון שעולה מעל הרקע הכהה.
2. שכבת WebGL קבועה עבור הטבעת והיהלום.

React משמש רק לשכבת התלת־ממד. שאר האתר נשאר HTML ו־JavaScript מודולרי, ולכן אין צורך לבצע שכתוב של כל האתר כיישום React.

## סדר האתחול

`src/main.js` מאתחל את האתר בסדר מכוון:

1. טעינת CSS ומצב האנימציה.
2. אתחול ScrollTrigger ו־Lenis.
3. יצירת תוויות היהלום, בחירת מתכת ואזור הגרירה.
4. התחלת הפתיח הטיפוגרפי.
5. בדיקת תמיכה ב־WebGL2.
6. טעינה עצלה של חבילת התלת־ממד.
7. המשך החלק השני של הפתיח רק לאחר שהטבעת רונדרה בפעם הראשונה.

הסדר הזה מאפשר לתוכן וללוגו להופיע לפני שחבילת Three.js הגדולה מסיימת להיטען.

## מצב משותף

`src/state.js` מכיל אובייקט mutable בשם `st`. GSAP משנה את הערכים שלו, ו־`Ring.jsx` ו־`CameraRig` קוראים אותם בכל פריים. כך נמנעים React re-renders בזמן גלילה.

| ערך | תפקיד |
| --- | --- |
| `intro` | מעבר מתקריב מאקרו לתנוחת Hero |
| `sweep` | מעבר אור בסביבת הסטודיו |
| `at` | מעבר מהטבעת לתצוגת האנטומיה |
| `ax`, `ay`, `as` | מיקום וקנה מידה של היהלום באנטומיה |
| `inspect` | תנועת הבדיקה הקולנועית |
| `cam` | עוצמת תנועת המצלמה |
| `velocity` | מהירות גלילה מנורמלת |
| `yaw`, `yawVel` | סיבוב וגרר אינרציאלי |
| `spinBoost` | סיבוב 360 מעלות מהכפתור |
| `out` | יציאת האובייקט לפני מקטע הצורות |

## גשר בין DOM לתלת־ממד

האובייקט `bridge` ב־`state.js` כולל callbacks של Ready ו־Failure. שכבת התלת־ממד מודיעה ל־DOM מתי הופיע הפריים הראשון או מתי אירעה תקלה. במקרה תקלה, הפתיח משתחרר והאתר ממשיך כאתר טיפוגרפי.

## אחריות הקבצים

- `src/dom/intro.js`: הפתיח הקולנועי.
- `src/dom/scroll.js`: Lenis, ScrollTrigger וכוריאוגרפיית הגלילה.
- `src/dom/labels.js`: הקרנת נקודות תלת־ממד לתוויות HTML.
- `src/dom/metalPicker.js`: בחירת מתכת וסנכרון UI.
- `src/dom/dragZone.js`: גרירה וסיבוב 360 מעלות.
- `src/dom/micro.js`: אינטראקציות מגנטיות ואור מקומי.
- `src/three/Experience.jsx`: Canvas, מצלמה, Quality Tiers ו־WebGL lifecycle.
- `src/three/Ring.jsx`: מודל, חומרים, תנוחות, צללים ונצנוצים.
- `src/three/studio.js`: סביבת צילום פרוצדורלית ו־PMREM.

## כללי הרחבה

- אנימציית DOM חדשה שייכת ל־`src/dom/`.
- התנהגות חומר, מצלמה או mesh שייכת ל־`src/three/`.
- ערך שצריך להיכתב ב־GSAP ולהיקרא ב־R3F שייך ל־`st`.
- תוכן עסקי ופעולות משתמש צריכים להישאר ב־HTML.
- אין ליצור render loop נוסף; R3F הוא הבעלים של הרינדור.
