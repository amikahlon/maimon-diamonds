# התאמת תוכן ועיצוב

## טקסטים וקישורים

רוב התוכן העסקי נמצא ב־`index.html`: ניווט, Hero, אנטומיית היהלום, צורות היהלומים וקריאה לפעולה.

לפני עלייה לאוויר יש להחליף קישורי WhatsApp ויצירת קשר, לבדוק את נוסחי המותג ולוודא שמידע על אבנים ומחירים מאושר עסקית.

## צבעי המותג

הצבעים המרכזיים נמצאים בתחילת `src/styles.css`:

| משתנה | שימוש |
| --- | --- |
| `--vellum` | רקע האתר |
| `--linen` | משטחים ומצבי hover |
| `--paper` | גוון זכוכית |
| `--ink` | צבע טקסט ולוגו |
| `--graphite` | טקסט משני |
| `--champagne` | הדגשות וקווי יוקרה |
| `--noir` | רקע "חדר התצוגה" (אנטומיה וצורות) |
| `--gilt` | הדגשות שמפניה על רקע כהה |
| `--hair` | גבולות וקווים דקים |

## מתכות

הגדרות המתכות נמצאות ב־`src/state.js` תחת `METALS`. כל אפשרות כוללת שם, צבע F0 (sRGB) ו־roughness. החומר הוא `metalness: 1`, ולכן הצבע צריך להיות בהיר (כמו `#f2d08f`), לא גוון כהה ש"מפצה" על מתכתיות חלקית. ה־`data-metal` של הכפתורים ב־`index.html` חייב להתאים למפתח ב־`METALS`.

## שינוי הטבעת

פרופורציות הטבעת מוגדרות ב־`scripts/build-ring.mjs` (חישוק דק של כ־1.9 מ"מ עם כתפי Cathedral עדינות). ניתן לשנות את הרדיוס הפנימי, עובי ורוחב החישוק, גובה הכתפיים, גודל האבן, מספר ה־prongs ומרווח אבני ה־Pavé.

לאחר שינוי יש להריץ `npm run build` ולבדוק את שלוש המתכות, את תקריב הפתיח ואת מקטע האנטומיה.

## פונטים

הפונטים נטענים כרגע מ־Google Fonts. שינוי metrics של פונט עלול לשנות את מיקום הטבעת, משום שה־Hero נמדד לפי המונוגרמה. לאחר שינוי פונט יש לבצע QA מחדש בכל רוחבי המסך.
