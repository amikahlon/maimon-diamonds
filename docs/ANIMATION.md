# אנימציות וגלילה

## מנועים

GSAP הוא מנוע האנימציה הראשי. Lenis מטפל בגלילה חלקה ו־ScrollTrigger ממפה את מיקום הדף למצב התלת־ממד.

אנימציות צריכות להתבסס בעיקר על `transform`, `opacity` וערכים מספריים ב־`st`. יש להימנע מאנימציה של מאפייני layout בזמן גלילה.

## הפתיח

הפתיח ב־`intro.js` מחולק לשני חלקים:

1. הרכבת מונוגרמת MD והופעת שם המותג.
2. תנועת הטבעת מתקריב מאקרו, מעבר אור והופעת ממשק ה־Hero. במקביל המונוגרמה ושם המותג דוהים לגוון "רוח" (`GHOST` ב־`intro.js`), כדי שהטבעת תהיה המוקד ולא תתחרה בטיפוגרפיה.

החלק השני ממתין לפריים הראשון של הטבעת. אם WebGL נכשל, ה־Promise משתחרר והפתיח ממשיך ללא התלת־ממד.

## מסע הגלילה

- `ring-to-anatomy`: מעבר מהטבעת לתצוגת היהלום.
- `diamond-inspection`: תנועת בדיקה ותנועת מצלמה.
- `anatomy-labels`: הצגת התוויות בדסקטופ.
- `hero-ui-exit`: ממשק ה־Hero (`#heroUi`) דוהה כשהיהלום עובר לאנטומיה.
- `nav-theme`: מוסיף `body.on-dark` כדי שהניווט יעבור לזכוכית כהה מעל חדר התצוגה.
- `ring-exit`: יציאת האובייקט לפני מקטע הצורות.
- `page-progress`: עדכון פס ההתקדמות ומספר הפרק.

`gsap.matchMedia()` מגדיר choreography נפרדת לדסקטופ, מובייל ו־Reduced Motion. שינויים רספונסיביים באנימציה צריכים להיכנס למנגנון הזה.

## Reveals ומיקרו־אינטראקציות

- SplitText מפצל כותרות למילים ומנפיש אותן פעם אחת.
- ScrollTrigger Batch חושף את כרטיסי הצורות בקבוצה ומוסיף `.drawn`, שמצייר את קווי הזהב (`pathLength="1"` + `stroke-dashoffset`).
- כפתורים מקבלים תנועה מגנטית רק במכשיר עם מצביע מדויק.
- כרטיסי הצורות משתמשים ב־CSS variables למיקום highlight.
- בחירת מתכת מפעילה משוב UI וגם sweep קצר בחומר.

## Reduced Motion

כאשר `prefers-reduced-motion: reduce` פעיל, Lenis, parallax, auto-rotation ונצנוצים לא חיוניים מושבתים. התוכן והטבעת מוצגים במצב יציב והפתיח אינו נועל את הדף.

## הוספת אנימציה

1. תנו ל־ScrollTrigger מזהה ברור.
2. השתמשו ב־scrub חלש יותר במובייל.
3. אל תעדכנו React state בכל callback של scroll.
4. הוסיפו cleanup כאשר יש listener או timeline ארוך חיים.
5. בדקו גלילה הפוכה, מעבר מהיר ורענון באמצע העמוד.
